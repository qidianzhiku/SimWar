# Third-Party Notices

The POC pins `pyblp==1.2.0` and its numerical dependencies by version in `requirements.lock`. The lock intentionally does not provide distribution hashes, and `sbom/cyclonedx.json` is an inventory rather than a complete license attestation or transitive provenance record. Reviewers must consult installed distribution metadata and upstream license texts before any redistribution. This reference tool is isolated, synthetic, and removable; it does not add a SimWar runtime dependency.
